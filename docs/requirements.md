# Business and Security Requirements

## Scenario

Northbridge Borough Council is a fictional UK public-sector
organisation undergoing cloud transformation.

The organisation currently operates several services within an
on-premises environment and intends to migrate selected workloads
to Microsoft Azure.

The organisation requires a secure hybrid architecture connecting
its existing environment to Azure.

## Business Requirements

- Maintain connectivity with existing on-premises systems.
- Support migration of selected applications to Azure.
- Provide secure remote administration.
- Centralise security monitoring.
- Support future cloud expansion.
- Minimise unnecessary exposure to the public internet.

## Security Requirements

- Apply least-privilege access.
- Implement network segmentation.
- Protect privileged administrative access.
- Encrypt sensitive data in transit and at rest.
- Centralise security logging and monitoring.
- Securely manage secrets and credentials.
- Implement preventative governance controls.
- Detect suspicious activity.
- Provide incident investigation capabilities.
- Support business continuity and resilience.

## Assumptions

This project represents a fictional organisation and contains
no real public-sector systems, credentials or citizen data.
